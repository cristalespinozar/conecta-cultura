Taller de programación para principiantes

Publicado el 18 de agosto de 2026

Este taller ofrece una introducción amable al desarrollo web para quienes nunca han programado. Se aprende paso a paso, con ejercicios cortos y apoyo entre pares.

Al finalizar, cada participante habrá construido una página sencilla y conocerá las bases de HTML, CSS y JavaScript.

Información de la actividad

  • Fecha: miércoles 2 de septiembre.
  • Duración: 2 horas.
  • Requisito: computador portátil o teléfono con conexión a internet.
